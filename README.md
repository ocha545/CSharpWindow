# CSharpWindow Ver 0.0.1!
C++/CLIで作成されたC#用ウィンドウライブラリです
Win32APIでウィンドウを表示したり
RawInputでキー入力を取得できます

# Requirement
- Visual Studio 2022

# Build
基本的に以下の構成でビルド出来ます
- x64 Debug .NET Core
- x64 Debug .NET Framework
- x64 Release .NET Core
- x64 Release .NET Framework
- Win32 Debug .NET Core
- Win32 Debug .NET Framework
- Win32 Release .NET Core
- Win32 Release .NET Framework
<br>
それぞれ以下のように出力されます
```C#
x64/
├── Debug-netcore/<br>
│    ┣━ CSharpWindow.dll
```
